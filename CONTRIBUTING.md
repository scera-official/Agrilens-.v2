# Contributing to AgriLens

Thanks for taking an interest in AgriLens.

The most helpful contributions are practical: tested fixes, clearer explanations, accessibility improvements, reliable crop-image test cases, and documentation that reflects what the hardware actually does.

When suggesting a change:
- Explain the problem it addresses.
- Mention the board and library versions used for testing.
- Be clear about what you tested and what remains untested.
- Do not include API keys, Wi-Fi passwords, or private crop images.
- Avoid presenting AI-generated crop assessments as confirmed diagnoses.

Small, well-explained improvements are welcome.
